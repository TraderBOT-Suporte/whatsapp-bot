Política de Privacidade

Última atualização: —

1. Informações que recolhemos

  • Token de acesso — usado para autenticação e identificação da sua conta.
  • Subscrição de notificações push — endpoint e chaves técnicas, para enviar alertas de sinais.
  • Watchlist — lista de ativos que escolheu monitorizar (guardada nos servidores).
  • Histórico de sinais — registos dos sinais recebidos.

2. Como usamos os dados

Os dados são usados exclusivamente para:

  • Autenticar o acesso à plataforma;
  • Enviar notificações de sinais em tempo real;
  • Guardar as suas preferências entre sessões;
  • Mostrar o histórico de sinais no painel.

3. Onde os dados ficam armazenados

Usamos a infraestrutura Google Firebase (Firestore) para armazenamento seguro, com encriptação em trânsito (HTTPS) e em repouso.

4. Partilha de dados

Não vendemos, alugamos nem partilhamos os seus dados pessoais com terceiros. Os dados são usados apenas internamente para o funcionamento do serviço.

5. Notificações push

As notificações são enviadas através do protocolo Web Push (VAPID). Pode desativá-las a qualquer momento nas configurações do dispositivo ou no menu da app.

6. Segurança

Todas as comunicações são encriptadas via HTTPS. Os tokens são armazenados em formato hash (SHA-256) nos servidores.

7. Os seus direitos

Pode, a qualquer momento:

  • Terminar sessão e limpar os dados locais;
  • Solicitar a remoção da conta e dados associados;
  • Desativar notificações push.

8. Aviso financeiro

O Trader BOT é uma ferramenta de análise técnica automatizada. Não constitui aconselhamento financeiro. Todas as decisões de investimento são da exclusiva responsabilidade do utilizador.

9. Contacto

Para questões sobre privacidade: traderbotanalyzer@zohomail.com

10. Alterações a esta política

Podemos atualizar esta política periodicamente. A data de "última atualização" no topo será sempre a referência.
